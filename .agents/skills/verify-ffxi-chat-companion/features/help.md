# Command discovery

## Sub-features

List the allowed commands and learn how to mention Kupobot.

## How to get to it (user POV)

Send `!help` in live chat.

## Driving it with the offline verifier

Run the skill's Drive block. Locate `viewer> !help` and its paired `bot>` reply. It lists `!status, !zone, !why, !project, !help` and introduces `@Kupobot`.

## Gotchas

The batch uses fixture viewer IDs; it does not prove rate limiting or posting to YouTube.
