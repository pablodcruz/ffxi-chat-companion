# Mention while AI is offline

## Sub-features

Get a useful fallback when AI questions are disabled.

## How to get to it (user POV)

Send a question directly to `@Kupobot`, e.g. `@Kupobot How does reactive combat work?`.

## Driving it with the offline verifier

Run Drive and check this input is paired with the AI-offline fallback that points to `!help`.

## Gotchas

A real model response requires separate authorization and is not tested by this synthetic run.
